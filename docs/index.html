FAQ

常见问题

需要安装 TeX Live 吗？
编译功能需要 TeX Live 2022/2023/2024 或 MiKTeX。编辑器自动检测路径，未找到时可在设置中手动指定。AI 对话不依赖 TeX Live。
模板创建后如何编译？
从模板库创建后会自动打开 main.tex 并固定主文档；编译时会按 documentclass 自动选择 pdflatex 或 xelatex。也可在设置中手动指定引擎。
墨灵 AI 需要付费吗？
墨灵免费，需自备 API Key（如 DeepSeek）。API 费用由服务商收取。
支持 macOS / Linux 吗？
目前仅 Windows 10/11。基于 Electron，理论可跨平台但未测试。
数据会上传云端吗？
不会。所有操作本地完成。仅 AI 对话内容发送给你配置的服务商。
