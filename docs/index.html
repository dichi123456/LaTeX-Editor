常见问题

你可能想知道

需要安装 TeX Live 吗？
编译功能需要 TeX Live 2024（或其他版本）。编辑器自动检测安装路径，未找到时可在设置中手动指定。AI 对话功能不依赖 TeX Live。
墨灵 AI 需要付费吗？
墨灵本身免费，需要你自备 AI 服务 API Key（如 DeepSeek、OpenAI）。API 费用由服务商收取，编辑器不额外收费。
支持 macOS 和 Linux 吗？
目前仅支持 Windows 10/11。基于 Electron 框架，理论上可跨平台，但尚未针对其他系统测试。
数据会上传到云端吗？
不会。所有文件操作、编译、预览均在本地完成。仅当你主动使用墨灵 AI 时，对话内容发送给你配置的 AI 服务商。
