FAQ

常见问题

需要安装 TeX Live 吗？
编译功能需要 TeX Live 2024。编辑器自动检测路径，未找到时可在设置中手动指定。AI 对话不依赖 TeX Live。
墨灵 AI 需要付费吗？
墨灵免费，需自备 API Key（如 DeepSeek）。API 费用由服务商收取。
支持 macOS / Linux 吗？
目前仅 Windows 10/11。基于 Electron，理论可跨平台但未测试。
数据会上传云端吗？
不会。所有操作本地完成。仅 AI 对话内容发送给你配置的服务商。
