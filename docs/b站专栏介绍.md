## 正文

大家好，我是 dichi。

折腾 LaTeX 的同学应该都踩过这些坑：Overleaf 要联网、要注册，论文涉密的时候根本不敢往上传；TeXstudio 装完还要自己配字体、调编译链，中文文档一编译就红屏报错。

最近我用 Electron + Vue 写了一个 Windows 桌面 LaTeX 编辑器，定位很简单——**本地、轻量、中文友好，顺便塞了个 AI 助手**。

今天分享一下这个项目，源码已开源在 GitHub。

### 它长什么样

四区域面板布局，左边文件树，中间编辑器，右边 PDF 预览，最右侧是 AI 对话。四个面板都可以拖拽调整大小，也能互换位置，用起来很自由。

![主界面截图](截图1.png)

### 核心功能

**编辑器**
- CodeMirror 6 驱动，LaTeX 语法高亮、行号、代码折叠
- 命令/环境/引用键智能补全，打 `\cite{` 会自动扫描 `.bib` 文件里的引用键
- 正则查找替换、多标签页、拖拽排序

**编译**
- 一键 F5 编译，支持 XeLaTeX / pdfLaTeX / LuaLaTeX / latexmk
- TeX Live 2024 自动检测，状态栏直接显示 ✓
- 编译日志面板，错误可以点击跳转到源码对应行

**PDF 预览**
- 内置 PDF.js，连续滚动、Ctrl+滚轮缩放
- **SyncTeX 正反向同步**：编辑器 Ctrl+Click 直接跳到 PDF 对应位置，反过来也行
- 支持打开外部 PDF 当参考

**墨灵 AI 助手**

这是我觉得最有意思的部分。不是简单的聊天窗口，而是一个 **Agent 模式的写作助手**：

- 对接 DeepSeek / OpenAI / Moonshot 等任何 OpenAI 兼容 API
- AI 可以直接**读取、搜索、修改你的项目文件**，改完编辑器实时刷新
- 选中一段代码，行号自动附加给 AI，它能精确定位，不用重读整个文件
- 编译报错时，点「分析编译错误」一键把日志丢给 AI 分析
- `replace_text` 精准替换，不会动到你没让它动的部分

### 中文支持

这一点单独说。默认配置就是 **XeLaTeX + ctex 宏集 + Windows 系统字体**（宋体/雅黑/仿宋），新建中文文档直接就能编译，不用去网上搜怎么配 `\setCJKmainfont`。

内置了 5 套中文模板：
- 中文论文
- 实验报告
- 中文简历
- Beamer 幻灯片
- 英文论文

新建的时候选模板就行，省得从空白开始。
